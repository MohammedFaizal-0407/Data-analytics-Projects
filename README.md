## 📁 Repository Overview

This repository contains a collection of **real-world data analytics projects** built using Microsoft Excel, covering domains such as financial analytics, FMCG, retail, and productivity. Each project demonstrates end-to-end analytical workflows — from raw data cleaning to dashboard creation and business insights.

---

## 🗂️ Projects

---

### 1. 💰 Billionaires Statistics Dataset
**File:** `Billionaires Statistics Dataset Raw.xlsx`

**Overview:**
Exploratory data analysis on a global dataset of billionaires, uncovering wealth distribution patterns, industry dominance, and demographic insights.

**Key Highlights:**
- 📌 Cleaned and structured raw billionaire data for analysis
- 🌍 Analyzed wealth distribution across countries and industries
- 📈 Built summary statistics and visualizations for net worth trends
- 🏭 Identified top industries producing billionaires globally

**Skills Used:** Data Cleaning, Pivot Tables, Conditional Formatting, Charts & Visualizations

---

### 2. 🛒 BlinkIT Grocery Data Analysis
**File:** `BlinkIT Grocery Data Excel.xlsx`

**Overview:**
Sales and operational analysis of BlinkIT (formerly Grofers), India's leading quick-commerce grocery platform — focusing on product performance, outlet types, and customer ratings.

**Key Highlights:**
- 🧹 Cleaned and standardized grocery sales data across multiple outlet types
- 📦 Analyzed sales performance by item category, fat content, and outlet size
- ⭐ Evaluated customer ratings and their correlation with item visibility
- 🏪 Compared Tier 1, Tier 2, and Tier 3 city outlet performance

**Skills Used:** Data Cleaning, VLOOKUP, Pivot Tables, Charts, Slicers

---

### 3. 🥤 Coca-Cola Sales Dashboard
**File:** `Cocacola Dashboard.xlsx`

**Overview:**
An interactive Excel dashboard analyzing Coca-Cola's beverage sales across regions, brands, and retailers — built to support business performance monitoring.

**Key Highlights:**
- 📊 Built an interactive dashboard with slicers for dynamic filtering
- 🗺️ Analyzed regional sales performance across US markets
- 🥤 Compared brand-wise revenue (Coca-Cola, Dasani, Sprite, Fanta, etc.)
- 📉 Tracked operating profit margins and units sold by retailer

**Skills Used:** Dashboard Design, Pivot Charts, Slicers, Conditional Formatting, KPI Metrics

---

### 4. 🌎 Sales Dashboard — South America 2022
**File:** `Sales DashBoard South America 2022.xlsx`

**Overview:**
A comprehensive sales performance dashboard for a South American market covering 2022, enabling region-wise and product-wise business decision-making.

**Key Highlights:**
- 📅 Tracked monthly and quarterly sales trends across 2022
- 🗺️ Broke down performance by country/region within South America
- 🏆 Identified top-performing products and sales representatives
- 💹 Calculated YoY growth metrics and revenue targets vs. actuals

**Skills Used:** Dashboard Design, Pivot Tables, Dynamic Charts, Data Aggregation, Trend Analysis

---

### 5. ✅ Task Management Tracker
**File:** `Task Management Tracker START.xlsx`

**Overview:**
A structured Excel-based task management and productivity tracker designed to monitor project tasks, deadlines, priorities, and completion status.

**Key Highlights:**
- 📋 Organized tasks by priority, status, owner, and due date
- 🔴🟡🟢 Color-coded conditional formatting for task urgency and status
- 📆 Tracked task completion rates and overdue items
- 📊 Summary view with progress metrics and team workload distribution

**Skills Used:** Conditional Formatting, Data Validation, Formulas (IF, COUNTIF, TODAY), Structured Tables

## 🚀 How to Use

1. **Clone or download** this repository
2. Open any `.xlsx` file in **Microsoft Excel** (2016 or later recommended)
3. Enable editing if prompted
4. Use **slicers and filters** on dashboard files for interactive exploration
5. Refer to individual sheets within each file for raw data, analysis, and visuals
